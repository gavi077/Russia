Что сознательно отложено:
- реальные карточки санаториев КБР;
- реальные карточки конкретных производителей и товаров;
- реальные карточки практик;
- реальные данные API sanatoria.ru и zdorovo100.ru;
- backend, база PostgreSQL, авторизация, реальные формы и модерация;
- юридически утвержденная политика обработки персональных данных.

Главный утвержденный дизайн, карта России, флаг и визуальный стиль сохранены.


Версия 7:
- добавлена настоящая интерактивная карта map.html;
- OpenStreetMap + Leaflet;
- слои: места размещения, производители, практики, курортные зоны, природные точки;
- фильтрация слоев;
- список объектов и кликабельные pop-up карточки;
- переключение КБР / вся Россия;
- карта связана с главной страницей и остальными разделами;
- демонстрационные координаты легко заменить данными из backend/API.


Версия 8:
- версия 7 полностью включена;
- карта получила кликабельные границы регионов;
- добавлен поиск по перечню 89 субъектов в российском правовом представлении;
- включены Донецкая Народная Республика, Луганская Народная Республика, Запорожская область и Херсонская область;
- регионы подсвечиваются при наведении и масштабируются при клике;
- Кабардино-Балкария ведет на kbr.html, остальные регионы подготовлены для последующего наполнения;
- сохранены слои объектов: размещение, производители, практики, курортные зоны, природные точки;
- на главной используется нейтральная подпись «Открыть карту»;
- добавлена нейтральная информационная пометка о различии российского правового представления и международно-правового статуса части территорий.

Границы:
- интерактивный региональный слой загружается как TopoJSON;
- базовая карта: OpenStreetMap;
- рендер: Leaflet;
- TopoJSON client: topojson-client.

Версия 10:

- добавлена кнопка «Назад» на внутренних страницах;
- добавлено автодополнение регионов в поисковых полях и формах;
- список регионов используется также на странице карты.
