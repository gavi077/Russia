Оздоровительная карта России - версия 3

По умолчанию:
- новая карта справа;
- триколор + георгиевская лента внутри карты;
- карта занимает не менее 25% экрана;
- фотографии удалены.

Возможность фото сохранена:
1. загрузить assets/map-photo.jpg
2. вызвать setMapPhoto("assets/map-photo.jpg")
3. вернуть патриотическую карту функцией setPatrioticMap()
