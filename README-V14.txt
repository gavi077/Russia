# v14 - визуальный патч

Этот пакет специально сделан как минимальный патч поверх текущего рабочего сайта.

Заменить на GitHub только:
- site.css
- site.js

Добавить:
- assets/logo/ozdorovitelnaya-logo.png

НЕ заменять:
- map.html
- map-yandex.js
- yandex-config.js
- regions.html
- regions-autocomplete.js
- остальные HTML-файлы

Что делает патч:
1. Ставит присланный фирменный логотип вместо временного символа ✦ в шапках и подвалах.
2. Убирает декоративные emoji-значки на внутренних страницах, но не трогает главную.
3. Делает полупрозрачный синий слой плотнее, чтобы белый текст читался четче.
4. Сохраняет фон природы видимым.
5. Не меняет карту, региональные данные, Yandex API или навигационную логику.
